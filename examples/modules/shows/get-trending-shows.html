    Get Trending Shows

    In this example we get trending shows.

    Since we do not need authentication or authorization for this example, only the Client-ID is required.

    string clientID = Console.ReadLine() ?? "";

var client = new TraktClient(clientID, "");

    The following lines show how to get trending shows.

    TraktPagedResponse<TraktTrendingShow> trendingShowsResponse = await client.Shows.GetTrendingShowsAsync(TraktExtendedInfo.Full);

foreach (TraktTrendingShow trendingShow in trendingShowsResponse)
{
    Console.WriteLine($"Watchers: {trendingShow.Watchers}, Title: {trendingShow.Show?.Title}, Year: {trendingShow.Show?.Year}, Rating: {trendingShow.Show?.Rating}");
}

    For getting a specific page, pass page and limit arguments.

    TraktPagedResponse<TraktTrendingShow> trendingShowsResponse = await client.Shows.GetTrendingShowsAsync(
    TraktExtendedInfo.Full,
    page: 2,
    limit: 10
);

foreach (TraktTrendingShow trendingShow in trendingShowsResponse)
{
    Console.WriteLine($"Watchers: {trendingShow.Watchers}, Title: {trendingShow.Show?.Title}, Year: {trendingShow.Show?.Year}, Rating: {trendingShow.Show?.Rating}");
}
