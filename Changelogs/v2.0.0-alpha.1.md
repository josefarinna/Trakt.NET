Changelog for Version 2.0.0-alpha.1 (2026-07-26)
===

Major Features & Architectural Changes:

- **New & Expanded API Modules**
  - **`SmartLists`** (`client.SmartLists`): Added support for Trakt Smart Lists management, creation, and filtering.
  - **`SocialRecommendations`** (`client.SocialRecommendations`): Added support for social network media recommendations.
  - **`Notes`** (`client.Notes`): Added support for Trakt Notes API (attaching notes to movies, shows, seasons, episodes, and items).
  - **`Team`** (`client.Team`): Added support for Trakt Team staff and contributor information.
  - **`Watchnow`** (`client.Watchnow`): Added support for WatchNow streaming source providers, offers, and pricing by region. *Note: WatchNow methods are provided for API completeness and visibility; availability or functionality may vary depending on Trakt backend support and API access level.*
  - **`Younify`** (`client.Younify`): Added support for Younify service connection integrations.
  - **`Users` / `Sync` Extensions**: Added support for Plex connections (`client.Users.GetPlexSettingsAsync()`, `ConnectPlexAsync()`), Favorites (`client.Sync.GetFavoritesAsync()`), User Limits, User Hidden Items, and Personal Lists.

- **Migration to Concrete Record Data Models (Removal of Interfaces)**
  - Replaced all `ITrakt...` interface types with concrete C# `record class` models (`TraktShow`, `TraktMovie`, `TraktEpisode`, `TraktSeason`, `TraktPerson`, `TraktUser`, `TraktList`, etc.).
  - Unified namespace to `TraktNET`.
  - Improved type safety, reduced memory allocation overhead, and enabled native record immutability features.

- **Comprehensive Media Image Support**
  - Added support for fetching image URLs across Trakt objects including Shows, Movies, Seasons, Episodes, People, Users, and Lists.
  - Introduced `TraktExtendedInfo.Images` (flag `512`) to include image metadata in API requests.
  - Added concrete image data models (`TraktShowImages`, `TraktMovieImages`, `TraktEpisodeImages`, `TraktSeasonImages`, `TraktPersonImages`, `TraktUserImages`, `TraktListImages`, etc.).

- **C# Source Generator for JSON Serialization (`Trakt.NET.SourceGeneration`)**
  - Integrated `System.Text.Json` source generation for zero-reflection, highly performant JSON serialization and deserialization.
  - Auto-generation of JSON serializer contexts (`JsonSerializerContextFactory`, `SerializerContexts`) across all Trakt request and response objects.

- **Native AOT & Assembly Trimming Support**
  - Configured library properties (`IsTrimmable` for .NET 6+ and `IsAotCompatible` for .NET 8+) ensuring full compatibility with Native AOT compilation and application trimming.

- **Modern .NET Target Framework Expansion**
  - Updated library target frameworks to support .NET 6.0, .NET 7.0, .NET 8.0, .NET 9.0, and .NET 10.0 alongside .NET Standard 2.0/2.1 and .NET Framework 4.7.2/4.8.1.
  - Modernized testing suite using xUnit v3 and Verify snapshot testing for source generation validation.

Updated & Improved:

- Enhanced `AuthenticationRequestHandler` for authorization header processing.
- Refactored `Trakt.NET.HttpClientFactory` extensions for HTTP client life-cycle management.
- Comprehensive unit test coverage for new JSON serializer contexts and concrete model parsing.
