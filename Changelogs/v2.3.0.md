Changelog for Version 2.3.0
===

New Features & API Endpoints:

- **Anticipated Recommendations (`client.Movies`, `client.Shows`, `client.Media`, `client.Recommendations`)**
  - Added support for personalized anticipated recommendations:
    - `GET /movies/recommendations/anticipated` via `client.Movies.GetAnticipatedRecommendationsAsync` (alias `GetAnticipatedMovieRecommendationsAsync`).
    - `GET /shows/recommendations/anticipated` via `client.Shows.GetAnticipatedRecommendationsAsync` (alias `GetAnticipatedShowRecommendationsAsync`).
    - `GET /media/recommendations/anticipated` via `client.Media.GetAnticipatedRecommendationsAsync` (alias `GetAnticipatedMediaRecommendationsAsync`).
  - Added convenience access methods on `client.Recommendations`:
    - `GetAnticipatedMovieRecommendationsAsync`
    - `GetAnticipatedShowRecommendationsAsync`
    - `GetAnticipatedMediaRecommendationsAsync`

Added & Updated Data Models:

- **Recommendation Models**
  - Added `TraktAnticipatedMovieRecommendation` (`Movie`, `Score`, `Released`).
  - Added `TraktAnticipatedShowRecommendation` (`Show`, `Score`, `Released`).
  - Added `TraktAnticipatedMediaRecommendation` (`Movie`, `Show`, `Score`, `Released`, `Type`).

Improvements & Fixes:

- **Postman Collection**
  - Added requests for anticipated movie, show, and media recommendations to `Postman/v2.3.0/`.
