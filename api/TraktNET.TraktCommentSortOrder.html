    Enum TraktCommentSortOrder

    Determines the sort order for comments.

    Namespace: TraktNET
    Assembly: Trakt.NET.Ex.dll
    Syntax
    public enum TraktCommentSortOrder

    Fields

    Name Description
    Highest

    Comments will be sorted by highest comments first.
    Likes

    Comments will be sorted by the number of likes first.
    Lowest

    Comments will be sorted by lowest comments first.
    Newest

    Comments will be sorted by newest comments first.
    Oldest

    Comments will be sorted by oldest comments first.
    Plays

    Comments will be sorted by the number of plays first.
    Replies

    Comments will be sorted by the number of replies first.
    Unspecified

    An invalid sort order.
    Watched

    Comments will be sorted by most watched first.
