    Enum TraktExtendedInfo

            Determines the possible extended options for Trakt API requests, allowing retrieving of additional data.


            This enum can be used as a flag and multiple values can be combined.


            See <a href="https://trakt.docs.apiary.io/#introduction/extended-info">"Trakt API Documentation - Extended Info"</a> for more information.
    Namespace: TraktNET
    Assembly: Trakt.NET.Ex.dll
    Syntax
    [Flags]
public enum TraktExtendedInfo

    Fields

    Name Description
    Browsing

    Browsing information shall be retrieved.
    Comments

    Comment media object information shall be retrieved.
    Episodes

    Episodes information shall be retrieved.
    Full

    Full information for media objects shall be retrieved.
    GuestStars

    Guest stars information shall be retrieved.
    Images

    Media images shall be retrieved.
    Metadata

    Metadata information shall be retrieved.
    Min

    Minimum information for media objects shall be retrieved.
    NoSeasons

    No seasons information shall be retrieved.
    None

    No additional data shall be retrieved.
    Progress

    Progress information shall be retrieved.
    Subgenres

    Subgenres information shall be retrieved.
    VIP

    User VIP information shall be retrieved.
