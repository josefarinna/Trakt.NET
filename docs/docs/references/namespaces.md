# Namespaces

This is an overview of all namespaces in the **Trakt.NET** v2.0 library.

| Namespace | Contents |
| ---------- | -------- |
| [`TraktNET`](xref:TraktNET) | Global unified namespace containing [`TraktClient`](xref:TraktNET.TraktClient), all data models (`TraktShow`, `TraktMovie`, `TraktEpisode`, etc.), enumerations (`TraktExtendedInfo`, `TraktSortBy`, etc.), exceptions, request parameters (`TraktFilter`), response wrappers (`TraktPagedResponse<T>`, `TraktResponse<T>`), post builders (`TraktSyncFavoritesPostBuilder`, etc.), and System.Text.Json serializer contexts (`JsonSerializerContextFactory`). |
