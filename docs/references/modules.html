    Modules

    The modules in the library represent each section in the official Trakt API documentation. You do not create a new instance of any module directly. Access each module through a TraktClient instance.

    Authentication

    This module contains all methods described in the Trakt API OAuth and Device Authentication sections.

    Access this module via TraktClient.Auth.

    Calendar

    This module contains all methods described in the Trakt API Calendar section.

    Access this module via TraktClient.Calendar.
